# Meru Global Team

Official website for Meru Global Team (meruglobalteam.org) — Carrying Christ's name into places where He is yet unknown.

## Technology Stack
- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4
- **Database**: PostgreSQL (Prisma ORM)
- **Deployment**: Render

## Getting Started

Run the development server:

```bash
npm run dev
```
 
Open [http://localhost:3000](http://localhost:3000) with your browser.

## Production Build

```bash
npm run build
npm start
```
